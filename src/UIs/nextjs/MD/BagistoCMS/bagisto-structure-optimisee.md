## 13. Recommended Page Speed & Technical SEO

### Optimisations
- **Lazy loading images** : hero, portfolio, testimonials
- **Code splitting** : charger CSS/JS par section visible
- **Compression assets** : Gzip/Brotli (95%+ ratio)
- **Resource hints** : dns-prefetch, preconnect links clés
- **CLS mitigation** : reserve space images, fontes système fallback

### Checklist Core Web Vitals
- LCP < 2.5s (Largest Contentful Paint)
- FID < 100ms (First Input Delay)
- CLS < 0.1 (Cumulative Layout Shift)
